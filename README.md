# Grey Knight

北京理工大学大二计算机学院网站开发小学期作业

## 项目名称

《Grey Knight》

## 项目概况

共有9个页面：

| 页面               | 作用                           |
| ------------------ | ------------------------------ |
| `index.html`       | 首页与游戏入口                 |
| `login.html`       | 登录                           |
| `register.html`    | 注册                           |
| `game/story.html`  | 序章剧情，可前后阅读或跳过     |
| `game/event.html`  | 断桥抉择，显示开局代价与收益   |
| `game/battle.html` | 卡牌战斗                       |
| `game/cards.html`  | 卡牌图鉴，搜索、筛选与规则查阅 |
| `game/rules.html`  | 操作说明                       |
| `team/index.html`  | 团队介绍                       |

## 项目类型

基于 HTML5、CSS3 和 JavaScript 平台的卡牌对战RPG游戏。
